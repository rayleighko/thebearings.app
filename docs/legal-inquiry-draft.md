# 금융규제·법령해석 질의 초안 (#4)

> 제출처: 금융규제민원포털(better.fsc.go.kr) → 법령해석·비조치의견서 → 법령해석 신청
> 익명(개인) 신청 가능. 아래 초안을 검토·수정 후 본인이 제출.
> 팁: 질의는 "우리 서비스가 되나요?"가 아니라 **사실관계를 구체적으로 고정**하고 "이 구조가 §6⑧의 투자일임에 해당하는지"를 묻는 형식이 회신 품질이 좋음.

---

## 제목

소프트웨어 도구를 통한 사용자 승인형 주문 실행 구조의 투자일임업(자본시장법 §6⑧) 해당 여부

## 질의 배경 (사실관계)

본인은 개인투자자가 스스로 정한 포트폴리오 원칙에 따라 계좌를 관리하도록 돕는 소프트웨어 도구(웹 서비스)의 개발을 검토 중입니다. 구체적 구조는 다음과 같습니다.

1. 사용자는 본인 명의로 증권사에서 직접 발급받은 Open API 키를 본인 기기(브라우저/PC)에만 보관합니다. **API 키 및 계좌 잔고 원본 정보는 서비스 운영자의 서버에 전송·저장되지 않습니다.**
2. 사용자는 서비스가 제공하는 일반적 자산배분 전략 템플릿(예: 주식 60/채권 40, 올웨더형 등 — 특정 종목이 아닌 자산군 비중 규칙) 중 하나를 스스로 선택하고, 목표 비중과 리밸런싱 조건(예: 괴리 5%p 이상)을 스스로 설정합니다.
3. 설정된 조건이 충족되면, 소프트웨어는 "현재 보유 비중과 사용자가 설정한 목표 비중의 차이를 해소하기 위한 주문 목록(종목·수량·주문유형)"을 **화면에 표시(프리뷰)**합니다. 이 프리뷰 생성은 사용자가 사전에 설정한 수식의 기계적 계산 결과이며, 운영자 또는 인공지능의 재량적 판단이 개입하지 않습니다.
4. 주문은 **사용자가 프리뷰 내용을 확인하고 건별로 명시적 승인(확인 버튼)을 한 경우에만**, 사용자 기기에서 사용자 본인의 API 키로 증권사에 직접 전송됩니다.
   - 승인의 유효시간은 수 분 이내로 제한되며, 승인된 프리뷰와 실제 전송 주문의 내용은 동일함이 기술적으로 보장됩니다(해시 대조).
   - "향후 자동 실행" 등 포괄 위임 기능은 제공하지 않습니다. 사용자가 승인하지 않으면 어떠한 주문도 전송되지 않습니다.
5. 서비스의 대가는 거래량·거래대금과 무관한 정액 구독료이며, 특정 증권사 계좌 개설 유도나 거래 연동 수수료는 수취하지 않습니다.

## 질의 사항

1. 위 1~5의 사실관계와 같이, 소프트웨어가 사용자가 사전에 스스로 설정한 규칙의 기계적 계산 결과를 주문 프리뷰로 제시하고, **사용자가 매 건 명시적으로 승인한 경우에만 사용자 본인의 API 키로 주문이 전송되는 구조**를 영업으로 제공하는 행위가 자본시장법 제6조 제8항의 투자일임업("투자판단의 전부 또는 일부를 일임받아 운용")에 해당하는지 여부
2. (해당하지 않는 경우) 승인 방식이 개별 종목 주문 단위가 아닌 **리밸런싱 1회분 주문 묶음(수 개 종목) 단위의 일괄 승인**인 경우에도 같은 결론이 유지되는지 여부
3. 위 구조에서 자산배분 전략 템플릿(특정 종목 아닌 자산군 비중 규칙)을 불특정 다수 이용자에게 동일하게 유료로 제공하는 행위가 투자자문업이 아닌 유사투자자문업(§101)의 신고 대상에 해당하는지 여부

## 참고 (신청인이 인지하고 있는 관련 해석)

- 귀 위원회의 기존 법령해석(유사투자자문업자가 자동매매 프로그램을 회원 계좌에 연동하여 자동으로 매매되도록 하는 행위는 투자일임업에 해당한다는 취지)은 인지하고 있으며, 본 질의는 **자동 실행이 존재하지 않고 매 건 사용자 승인이 개재**된다는 점에서 사실관계가 다릅니다.
- 대법원 2018도4413 판결(자동매매 프로그램 판매의 유사투자자문업 해당) 취지도 인지하고 있습니다.
